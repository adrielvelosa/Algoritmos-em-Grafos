# Grafos-Busca-em-Largura
Implementação de uma estrutura de **Grafo** (utilizando Lista de Adjacência) em Python dividida em dois arquivos, ambos executados diretamente através da função `main()`:

* **`bfs_padrao.py`**: Percorre o grafo em níveis e retorna a lista de vértices visitados.
* **`bfs_menor_caminho.py`**: Encontra o menor caminho entre um vértice de origem e um vértice de destino.
