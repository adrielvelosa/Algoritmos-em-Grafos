## Sobre esta Entrega
Implementação de uma estrutura de **Grafo** baseada em **Lista de Adjacência** em Python contendo os algoritmos de **Busca em Profundidade (Depth-First Search - DFS)** utilizando estrutura de **Pilha**:

* **`dfs_padrao.py`**: Explora o grafo avançando o máximo possível em cada ramificação antes de retroceder, retornando a lista com a ordem dos vértices visitados.
* **`dfs_ciclos.py`**: Adapta a pilha para rastrear o vértice anterior (`{'vertice': ..., 'pai': ...}`), permitindo identificar a existência de ciclos no grafo.

## Como Executar

    python dfs_padrao.py
    python dfs_ciclos.py
