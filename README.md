## Sobre esta Entrega
Implementação de uma estrutura de **Grafo** baseada em **Lista de Adjacência** em Python contendo os algoritmos de **Busca em Largura (Breadth-First Search - BFS)** utilizando estrutura de **Fila**:

* **`bfs_padrao.py`**: Percorre o grafo em níveis a partir de um vértice inicial e retorna a lista com a ordem completa dos vértices visitados.
* **`bfs_menor_caminho.py`**: Adapta a fila para armazenar o histórico do trajeto (`{'vertice': ..., 'caminho': ...}`), encontrando o menor caminho em número de arestas entre um vértice de origem e um de destino.

## Como Executar

    python bfs_padrao.py
    python bfs_menor_caminho.py
